# Navmoney

“Implement the Supabase database schema for investments, income transactions, expenses, categories, loans, EMI payments and user settings. Add migrations, foreign keys, constraints, indexes, authentication and strict per-user RLS policies. Audit all data access paths and verify that one user cannot read or modify another user's records.”
